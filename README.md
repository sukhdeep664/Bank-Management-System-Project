# 🏦 Bank Management System

A simple Bank Management System developed using Python and Object-Oriented Programming (OOP).

---

## 🚀 Features

- Create Bank Account
- Deposit Money
- Withdraw Money
- Show Account Details
- Update Account Details
- Delete Account
- Random Account Number Generation
- Data Storage using JSON

---

## 🛠 Technologies Used

- Python
- Object-Oriented Programming (OOP)
- JSON
- pathlib
- random
- string

## ▶️ How to Run

1. Clone the repository.
2. Run:

```bash
python main.py
```

3. Choose the required banking operation from the menu.
